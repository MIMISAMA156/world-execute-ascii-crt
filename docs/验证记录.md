```powershell
python terminal_player.py --check
```

## 显示验证边界

此前 Windows 适配已确认播放器进程在 Windows Terminal / ConPTY 下运行，传统控制台的字体 API 也已读回 Lucida Console、字重 400、像素高 22，并验证退出后恢复原字体。

窗口读取工具未返回 Windows Terminal，**未完成实际终端的 CRT 光晕截图核验**。参考视频在制作环境无法成功播放，未进行逐帧一致性比较。因此本仓库描述的是已配置的内置复古效果，不宣称与原视频的光晕强度、字体或每一帧完全一致。
